# MAGE-graph

The complete knowledge-graph dataset is grouped in one folder:

[`MAGE-graph-data/`](MAGE-graph-data/)

Inside that folder, each `output_N/` directory contains:

- `graph/full_output.json` — the knowledge graph
- `images/` — images referenced by that graph

The folder also contains the image-copy manifest and the list of image references that were not found in the local source data.

To download the dataset, use **Code → Download ZIP** on this repository and open `MAGE-graph-data/` after extraction.
